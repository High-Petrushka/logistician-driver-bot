# logistician-driver-bot
Бот для обеспечения взаимодействия логиста и водителя

## Запуск

1. Заполните `MAX_BOT_TOKEN` в `.env` токеном бота из MAX.
2. Выполните `npm run dev`.

Бот работает в режиме long polling через `@maxhub/max-bot-api`.

Команда `/id` отвечает `user_id` пользователя, отправившего команду.

Команда `/clear` удаляет сообщения бота в текущем чате. Сообщения пользователя
MAX не позволяет удалять ботам в личном диалоге.

После запуска бота пользователь получает кнопку «Начать». Нажатие на неё
открывает выбор роли: «Администратор», «Логист» или «Водитель».

Сертификат MAX хранится локально в `certs/` и подключается только к процессу
бота через `NODE_EXTRA_CA_CERTS`. Системное хранилище сертификатов macOS не
изменяется.
